# Transformer 的计算过程

25 页中文 HTML 幻灯讲义：用同一组三词、双头的教学参数，从词嵌入、Q/K/V 和注意力一直计算到词表概率。

- 第 3 页为完整长方体矩阵计算图，支持放大查看及 SVG 下载
- 方向键或底部控件翻页
- 注意力交互实验：选择 query、切换因果遮罩、逐步追踪计算
- 四节共 12 道递进习题，附可展开的提示与推导
- 讲义模式显示补充说明，手机自动启用
- 支持浏览器打印；单文件无需联网和构建依赖

直接打开 `index.html` 即可。示例参数未经训练，所有数值在浏览器内使用完整精度计算，显示时取三位小数。

参考文献见末页。图示及教学算例为此讲义自建。
